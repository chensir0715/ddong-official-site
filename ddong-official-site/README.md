# DDONG运动官网第一版

这是一个无需构建工具的响应式静态官网模板，包含首页、平台能力、合作对象、滑雪季场景、合作流程和联系入口。

## 本地预览
1. 解压文件。
2. 双击 `index.html`，用浏览器打开。

## 上线前必须替换
- 公司完整注册名称
- 真实商务联系方式
- DDONG运动小程序二维码
- 商务联系二维码或邮箱
- 隐私政策、用户协议和适用的备案信息
- 所有尚未落地的功能描述，确保与实际能力一致

## 免费部署思路
1. 创建 GitHub 账号和一个新的 repository。
2. 将 `index.html` 上传到仓库根目录并提交。
3. 在 Cloudflare Pages 创建项目，连接该 GitHub 仓库。
4. 选择静态 HTML / 不需要构建命令；输出目录填 `/` 或仓库根目录（按控制台提示）。
5. 使用平台提供的 `pages.dev` 测试地址检查页面。
6. 后续再购买域名并按托管平台指引绑定；如面向中国大陆提供服务，先核实适用的备案及其他合规要求。

## 说明
- 本版没有后端、数据库、表单提交系统或支付功能。
- 联系入口目前为内容占位，不会自动收集线索。
- 不要在网站展示未签约合作伙伴、未验证支付功能或尚未具备的资质。
